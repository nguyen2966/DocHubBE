TASK 3 — UPDATE DOCUMENT CONTROLLER
===================================

Update the endpoint:

```txt
GET /workspaces/:workspaceId/documents
```

It should use:

```ts

```

Import:

```ts
import { PagePaginationResponseInterceptor } from 'src/common/interceptors/page-paginated.interceptor'
import { DocumentListQueryDto } from './dto/document-list-query.dto'
```

Also ensure `Query` and `UseInterceptors` are imported from `@nestjs/common`, without duplicate imports.

The controller method should conceptually be:

```ts
@Get()
@RequireWorkspacePermission('workspace:view')
@UseInterceptors(PagePaginationResponseInterceptor)
async findAll(
  @Param('workspaceId') workspaceId: string,
  @Req() req: Request,
  @Query() query: DocumentListQueryDto,
) {
  const userId = req.user?._id.toString()

  const result = await this.documentService.findByWorkspace(
    workspaceId,
    query,
  )

  const documents = result.items

  if (!documents.length) {
    return {
      ...result,
      items: [],
    }
  }

  const docIds = documents.map((doc) => doc._id.toString())

  const permissionsMap =
    await this.permissionsService.getBulkDocumentPermissions(
      userId as string,
      workspaceId,
      docIds,
    )

  return {
    ...result,
    items: documents.map((doc) => ({
      ...doc,
      permissions: permissionsMap[doc._id.toString()] || [],
    })),
  }
}
```

Important:

* Preserve existing permission enrichment behavior.
* Preserve `@RequireWorkspacePermission('workspace:view')`.
* Preserve existing guards.
* The controller should return `items`, not `data`.
* Let `PagePaginationResponseInterceptor` convert `items` to `data`.
